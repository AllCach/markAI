# Установка MarkAI 0.11.2-beta.1

Текущая версия исходников — `0.11.2-beta.1` в `dev-beta`. После последних изменений итоговый архив ещё не пересобран и не принят как финальный релиз. Не определяйте версию по старому файлу в папке `mods`.

## Требования

Minecraft Java 26.3, Java 25, Fabric Loader 0.19.5 или новее и Fabric API для Minecraft 26.3. Версии зависимостей зафиксированы в `gradle.properties` и `fabric.mod.json`.

## Установка или обновление

1. Закройте Minecraft и сервер. Скопируйте **весь мир**, текущий JAR MarkAI и `config/markai.json` в безопасное место. При смене формата одного старого `markai.json` недостаточно для полного отката.
2. Возьмите JAR из заново собранного beta-архива или `build/libs/markai-0.11.2-beta.1.jar` после сборки текущего коммита. Не берите `-sources.jar`.
3. Удалите прежний активный JAR MarkAI из `mods` игрового профиля. Скопируйте новый JAR и Fabric API для 26.3. Если игра пишет `fabric-api is missing`, установите Fabric API именно для этого профиля.
4. Для выделенного сервера поставьте MarkAI и Fabric API на сервер **и** на клиенты. Настройки модели относятся к серверному процессу; `127.0.0.1` в серверном конфиге означает сам сервер.
5. Запустите игру на **копии** мира. Проверьте выбор и имя питомцев, сумки, журнал, сообщения и перезаход. После этого можно обновлять основной мир.

Обычные действия питомцев не требуют модели. Для диалога установите Ollama отдельно, загрузите модель `qwen3:8b` и запустите сервер, либо настройте совместимый API по [CONFIGURATION.md](CONFIGURATION.md). Скрипт `.\start-ollama.ps1` помогает запускать локальную Ollama; параметр `-Pull` загружает модель.

Внутри мира откройте «Настройки Minecraft → Настройки MarkAI», чтобы включить или выключить сохранение памяти питомцев. Эта настройка относится к серверу и доступна владельцу одиночного мира или оператору. После Shift-приручения экран предложит новый профиль или прежний профиль погибшего питомца того же вида.

Дикого волка добавляют Shift + ПКМ с костью после успешного приручения, курицу — Shift + ПКМ с семенами. Обычный ПКМ не регистрирует их. Подробнее: [README.md](README.md).

## Откат

Верните **весь мир** из резервной копии вместе с прежним JAR и конфигом. Новые файлы мира старый мод может не прочитать. Не заменяйте только `markai.json`: данные сущностей, в том числе сумка волка, лежат в сохранении мира.
