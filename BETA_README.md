# MarkAI 0.11.2-beta.1

Beta-кандидат для Minecraft Java 26.3 / Fabric. Волки и курицы становятся постоянными компаньонами с отдельными именами, памятью, опытом и командами. AI-диалог необязателен: питомцы двигаются и выполняют доступные задания без модели. Статус проверки конкретного пакета — [PRE_RELEASE_0.11.2.md](PRE_RELEASE_0.11.2.md).

## Установка

Нужны Java 25, Fabric Loader 0.19.5 или новее и Fabric API для 26.3. Закройте игру, сохраните полную копию мира, прежний JAR и конфиг. Поместите `markai-0.11.2-beta.1.jar` и Fabric API в папку `mods` нужного профиля, оставив один JAR MarkAI. Для выделенного сервера установите мод и Fabric API также на клиентов. Не устанавливайте `-sources.jar`. Для отката восстановите весь мир из копии.

Для разговоров установите Ollama и модель `qwen3:8b` отдельно. Скрипт `start-ollama.ps1 -Pull` может загрузить модель; обычный запуск не требует повторной загрузки. Настройки сервера — в `config/markai.json`. На выделенном сервере `127.0.0.1` относится к машине сервера.

## Первые действия

- Shift + ПКМ с костью по дикому волку: ванильная попытка приручения и регистрация после успеха. Обычный ПКМ с костью не добавляет волка в MarkAI.
- Shift + ПКМ с семенами по дикой курице: регистрация той же сущности. Обычный ПКМ сохраняет обычное кормление.
- Shift + ПКМ с пустой рукой по своему зарегистрированному волку: открыть сумку на девять слотов.
- U открывает общую панель, Y — общий чат, G/H/V — личные профиль/диалог/команды. Shift + V выбирает следующего питомца. Клавиши переназначаются в Minecraft.
- R/J/K — атака, сбор, остановка; B/M/N/O/P — ко мне, следовать, ждать, отдыхать, отметить дом. Ctrl + поддерживаемая клавиша даёт групповой приказ своим питомцам рядом.
- `/ma <сообщение>` — общий разговор, `/mo <сообщение>` — личный; `/mo <имя> <сообщение>` обращается к указанному питомцу. Ответы этих команд видны в обычном чате.

Волк собирает уже лежащие предметы в радиусе 16 блоков от точки начала задания; блоки он не добывает. Боевой радиус по умолчанию 32 блока. Курица не атакует и не носит сумку. После сообщения игрока питомцы могут обменяться не более чем десятью репликами.

## Данные и обратная связь

Личности и память сохраняются в мировом `markai.json`, журнал натуралиста — в `field-journal.json`, сумка волка — в сущности. Личные диалоги могут записываться в `logs/markai-chat.jsonl`. Перед отправкой логов удалите личный текст и ключи. Настройки: [CONFIGURATION.md](CONFIGURATION.md); проверки: [BETA_TESTING.md](BETA_TESTING.md); изменения: [CHANGELOG.md](CHANGELOG.md). Ошибки сообщайте в [GitHub Issues](https://github.com/AllCach/markAI/issues) с версией, шагами и результатом `/mark ai status`.
