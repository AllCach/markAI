# Living Companion: состояние реализации 0.10.0

Текущий проект — `D:/dev/markAI`, версия исходников 0.10.0. Добавлены общая панель U, настройки для всех своих питомцев и отдельный общий чат с контекстом и настоящими именами. Разговор после одного сообщения игрока ограничен десятью репликами всех питомцев вместе и может закончиться раньше. Личные истории отделены, отклик по имени работает только в общей вкладке. Установка — [INSTALLATION.md](INSTALLATION.md). Нижние сведения о 0.8.x–0.9.x сохранены как история.

Принятое техническое задание: [MASTER_TASK.md](MASTER_TASK.md).
Среда: Minecraft 26.3, Loader 0.19.5, Fabric API 0.163.0+26.3, Loom 1.18.4, Java 25, Gradle 9.7.1.

Подтверждённые результаты и ограничения: [TESTING.md](TESTING.md). Реализация не означает безошибочность любой языковой модели или совместимость с любым сторонним модом.

История 0.8.2: семь прямых переназначаемых клавиш команд, 672 проверки и реальный клиентский сценарий с горячими клавишами/полным экраном прошли. Тогда использовались серверные и живые проверки модели из 0.8.1. Результаты выпуска 0.9.0 — 771 проверка и 34 серверных сценария; живая модель в 0.9.0 заново не оценивалась.

0.9.0: отдельный реестр и сохранения до восьми волков на игрока, выбор/карточки/Shift+V, существующие Ctrl-команды для своей группы. Курица Mark, разные видовые роли и задания охраны/патруля на 32 блока ещё не добавлены. Точные актуальные проверки перечислены в RELEASE_REPORT.md; прежние строки относятся к соответствующим выпускам 0.8.x.
