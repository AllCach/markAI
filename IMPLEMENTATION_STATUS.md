# Living Companion: 0.10.4 beta — проверка выпуска

Текущая ветка `feature/0.10.4-vocal-fallback`, версия исходников 0.10.4 beta. При выключенном ИИ или недоступной модели компаньон поворачивается к владельцу и отвечает обычным волчьим звуком; отклик ограничен одним разом в три секунды. Проверки выпуска и ручные шаги собраны в [BETA_TESTING.md](BETA_TESTING.md).

Принятое техническое задание: [MASTER_TASK.md](MASTER_TASK.md).
Среда: Minecraft 26.3, Loader 0.19.5, Fabric API 0.163.0+26.3, Loom 1.18.4, Java 25, Gradle 9.7.1.
