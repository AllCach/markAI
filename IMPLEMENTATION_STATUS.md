# Living Companion: состояние реализации 0.8.2

Принятое техническое задание: [MASTER_TASK.md](MASTER_TASK.md).
Среда: Minecraft 26.3, Loader 0.19.5, Fabric API 0.163.0+26.3, Loom 1.18.4, Java 25, Gradle 9.7.1.

| Этап | Реализовано и границы |
| --- | --- |
| 1 Основа | Отдельные domain, personality, emotions, behavior, perception, actions, memory, AI, network, client, inventory, training, voice; исходный MarkBrain сохранён |
| 2 Волк | Walk/сохранённое имя; обычное приручение костями и принятие своего волка без замены UUID/здоровья/сумки; владелец, загрузка/выгрузка/смерть/возрождение, summon, dismiss |
| 3 Характер | Восемь постоянных черт; влияют на осторожность, самостоятельность, интерес, игру и контекст разговора |
| 4 Эмоции | Причинные реакции, нормализация и восстановление; влияют на действия и речь |
| 5 Поведение | 12 состояний, приоритеты, гистерезис, настоящий путь, отступление и защита с запретом союзных/мирных целей |
| 6 Наблюдение | Видимые существа в 16 блоках, загруженные видимые блоки, игрок, погода/свет/биом/угрозы; ограниченная типизированная история событий |
| 7 LLM | Ollama и OpenAI-compatible HTTP, отмена, ограничения, повторы временных ошибок, проверка схемы, характер говорящего волка |
| 8 Память | UUID и происхождение, факты/слова игрока/сводки, асинхронное извлечение, ограничение/сворачивание, поиск, просмотр и удаление |
| 9 Команды | Детерминированные FOLLOW/STAY/COME/REST/WANDER/RETURN_HOME/INVESTIGATE; отдельные явные tame/attack/collect/stop, настоящий бой и сбор в сумку; проверка и подтверждённый результат |
| 10 GUI | Пять настоящих вкладок, портрет, история и ввод, отмена, память с выбором/удалением/страницами, настройки и HUD, G/H/V |
| 11 Выразительность | Нативные взгляд, наклон головы, сидячий отдых, внимание к объекту, игровой прыжок, страх и ванильный хвост; отдельного скелетного аниматора нет |
| 12 Звук/голос | Контекстные лай/рычание/скуление/дыхание и штатное ранение. SpeechRecognizer/SpeechSynthesizer/VoiceSessionManager спроектированы; микрофон/STT/TTS не подключены |
| 13 Сеть | Типизированные ограниченные пакеты, права по игроку соединения, частота, личная история владельца |
| 14 Конфиг | Проверка параметров и адресов, резервная копия повреждённого файла; настройки компаньона отделены от ключей API |
| 15 Диагностика | status/debug/brain/mood/memory, результат действия, измерение наблюдений и задержки AI |
| 16 Проверки | 672 проверки логики/HTTP, 31 серверный GameTest, 5 живых проверок петли диалога; клиент/полный экран ранее проверены в 0.8.0 |
| 17 Производительность | Кэш, лимиты скана/истории/очередей/сети; измерение 201 наблюдения в игровом тесте. Долгая нагрузочная сессия не проводилась |
| 18 Документация | README, ARCHITECTURE, DEVELOPMENT, CONFIGURATION, TESTING и итоговый отчёт |
| 19 Приёмка | Создание, разговор, память, опасность, команды, HTTP-ошибки и GUI покрыты игровыми и автоматическими проверками; произвольный диалог зависит от модели |
| 20 Интеграция | Проверены разделение client/server, потоки, UUID, владение, сохранение, отмена, GUI и ошибки; результаты в TESTING/VALIDATION |

Подтверждённые результаты и ограничения: [TESTING.md](TESTING.md). Реализация не означает безошибочность любой языковой модели или совместимость с любым сторонним модом.

0.8.2: семь прямых переназначаемых клавиш команд, 672 проверки и реальный клиентский сценарий с горячими клавишами/полным экраном прошли. Серверные и живые проверки модели в таблице выше относятся к 0.8.1.
