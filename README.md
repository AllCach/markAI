# MarkAI — Living World

MarkAI добавляет в Minecraft Java 26.3 постоянных компаньонов: волков и куриц с именами, характером, памятью, уровнями и командами. Волк умеет защищать, собирать лежащие предметы и носить сумку; курица следует, наблюдает и избегает опасности. Разговоры через языковую модель необязательны: движение, задания, бой и штатные звуки работают без неё.

**Текущий статус:** исходники `0.11.3-beta.1` в ветке `dev-beta`. Это кандидат в разработке, не готовый релиз 1.0. Что реализовано и что ещё проверять: [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md), [WORK_PLAN.md](WORK_PLAN.md).

## Установка

Нужны Minecraft Java 26.3, Java 25, Fabric Loader 0.19.5 или новее и Fabric API для 26.3. Закройте игру, сделайте копию мира и замените прежний JAR MarkAI в папке `mods` нужного профиля. Должен остаться ровно один активный JAR MarkAI. На выделенном сервере мод и Fabric API нужны и серверу, и клиентам. Подробно: [INSTALLATION.md](INSTALLATION.md).

Локальная модель по умолчанию: Ollama на `http://127.0.0.1:11434` с `qwen3:8b`. Ollama и модель не входят в мод; конфигурация — [CONFIGURATION.md](CONFIGURATION.md).

## Добавление питомца

| Действие | Результат |
| --- | --- |
| Shift + ПКМ с костью по дикому волку | Ванильная попытка приручения; после успеха этот же волк регистрируется в MarkAI |
| Обычный ПКМ с костью | Только ванильное приручение, без регистрации |
| Shift + ПКМ с семенами по дикой курице | Эта же курица регистрируется в MarkAI |
| Обычный ПКМ с семенами | Обычное кормление курицы |
| `/walk tame` с прицелом на своего приручённого волка | Явная регистрация уже приручённого волка |
| Shift + ПКМ с пустой рукой по своему зарегистрированному волку | Сумка на девять слотов |

Чужие питомцы не принимаются; повторное взаимодействие не создаёт дубликат. Команды `/mark spawn` и `/mark spawn chicken` явно создают питомцев для тестирования. GUI не содержит кнопок создания.

После намеренного приручения открывается выбор профиля: **новый** или профиль ранее погибшего питомца **того же вида**. При выборе старого профиля его имя, память, характер, обучение и уровень переходят к только что приручённому животному; физическое животное и его UUID сохраняются. Живой профиль нельзя перенести на другое тело. Если закрыть окно, при свободном месте останется новый профиль; при полном списке животное останется без регистрации, пока не выбран старый профиль. Для курицы в этом случае семечко расходуется при успешном выборе профиля.

## Панели и управление

| Клавиши | Действие |
| --- | --- |
| U / Y | Общая панель / вкладка общего чата |
| G / H / V | Профиль выбранного / личный диалог / быстрые команды |
| Shift + V | Следующий питомец |
| R / J / K | Атаковать цель / собрать добычу / остановить задание |
| B / M / N / O / P | Ко мне / следовать / ждать / отдыхать / отметить дом |
| I | Сумка волка |
| Ctrl + клавиша приказа | Поддерживаемый групповой приказ своим питомцам в пределах 16 блоков |

Клавиши переназначаются в настройках Minecraft. Пока открыт экран или чат, игровые горячие команды не отправляются. Личная панель показывает здоровье, опыт, таланты, диалог, память и настройки. Общая панель содержит питомцев, совместимые приказы, общие настройки и чат. Выбор питомца не меняется от группового приказа.

В обычных **настройках Minecraft** есть кнопка «Настройки MarkAI». В мире владелец одиночного мира или оператор сервера может переключить «Сохранять память питомцев». Во вкладке «Настройки → Характер» каждого питомца есть личный переключатель сохранения памяти: он действует, когда общая настройка включена. Выключение оставляет память рабочей до выхода, но не записывает историю разговоров и событий этого питомца в мир. Диагностический файл `logs/markai-chat.jsonl` управляется отдельно.

`/ma <сообщение>` начинает общий разговор; `/mo <сообщение>` пишет выбранному питомцу; `/mo <имя> <сообщение>` адресует конкретному питомцу. Ответы этих команд показываются в обычном чате Minecraft. Во вкладке общего чата обращение по имени выбирает адресата; после одного сообщения игрока питомцы могут обменяться не более чем десятью репликами. Личный чат не маршрутизирует чужие имена. Модель может быть выключена командой `/mark ai off`.

## Задания и прогресс

Волк атакует разрешённую видимую цель под прицелом, собирает уже лежащую добычу в радиусе 16 блоков от начала задания и может охранять, патрулировать или исследовать территорию. Он не ломает блоки. Курица не получает волчьи боевые команды и сумку; для неё доступна роль наблюдателя. Питомцы получают опыт и тратят очки на видовые таланты; значения сохраняются отдельно. Журнал натуралиста отслеживает встреченных существ по физическому UUID, биомы, стадии изучения и личные заметки.

Полный список команд и границы действий: [CONFIGURATION.md](CONFIGURATION.md). Границы видов и архитектура: [ARCHITECTURE.md](ARCHITECTURE.md).

## Данные и разработка

Мировой `markai.json` хранит личности, выбор и настройки, а при включённом сохранении памяти — также разговоры и события; `field-journal.json` хранит журнал натуралиста. Сумка хранится вместе с сущностью волка. Диалоги также могут попадать в локальный `logs/markai-chat.jsonl`: удаляйте личный текст перед отправкой логов. Старый мод не обязан читать новый формат мира; для отката нужна полная копия мира.

Сборка требует JDK 25: `.\build.ps1 build` или `.\gradlew.bat build`. Текущий номер артефакта — `markai-0.11.3-beta.1.jar`; наличие файла в `build/libs` само по себе не доказывает, что он собран из последнего коммита. Проверки и выпуск: [TESTING.md](TESTING.md), [PRE_RELEASE_0.11.3.md](PRE_RELEASE_0.11.3.md). История изменений: [CHANGELOG.md](CHANGELOG.md).
