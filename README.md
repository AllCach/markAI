# MarkAI — Living Companion

Исходники подготовлены как beta-кандидат **0.10.4** в ветке **`feature/0.10.4-vocal-fallback`** проекта **`D:/dev/markAI`**; пользовательская установка в игру не менялась. Если ИИ выключен или модель недоступна, питомец отзывается волчьим голосом не чаще раза в три секунды.

**Группа:** Ctrl + R/J/K/B/N/M или Ctrl + кнопка команды применяет поддерживаемый приказ ко всем своим компаньонам в пределах 16 блоков. Доступны также отдых, прогулка, возврат домой и осмотр через Ctrl + кнопку. Общий стоп отменяет задания своих компаньонов, включая временно выгруженных. Выбор не меняется, чужие питомцы не получают приказ.

**Выбор:** стрелки и соседние карточки в панели, колесо над областью выбора или Shift + V в игре. Обычные команды и хоткеи относятся к выбранному компаньону. Повторный `/mark spawn` создаёт дополнительного волка и выбирает его; `/mark respawn` возрождает выбранного погибшего. Обычное приручение добавляет волка, сохраняя прежний выбор.

Мировой `markai.json` переводится в формат `schemaVersion: 1` с отдельным выбором на владельца. Перед первой записью прежнего формата создаётся точная копия `markai.json.pre-0.9-*.bak`. Сумки остаются у физических сущностей; память, обучение, имя и настройки хранятся отдельно для каждого компаньона. Старый мод не умеет читать новый формат: проверяйте обновление на копии мира.

Говорящий приручённый волк для **Minecraft Java 26.3 / Fabric**, beta-версия **0.10.4**. Walk становится компаньоном после приручения костями, атакует выбранную хозяином цель и складывает мясо и другие лежащие предметы в сумку. Боевой радиус настраивается в `config/markai.json` и по умолчанию равен 32 блокам. Мод сохраняет владельца и личность компаньона, разговоры, воспоминания, обучение и сумку. Перемещение, задания, бой и защита работают без языковой модели; модель отвечает за разговор.

Проект использует настоящие зависимости Minecraft 26.3: Java 25, Fabric Loader 0.19.5, Fabric API 0.163.0+26.3, Loom 1.18.4, Gradle 9.7.1. Имена классов Minecraft официальные, без Yarn.

В 0.8.1 исправлена петля ручного диалога: новое сообщение передаётся одним последним ходом, а повтор длинного ответа вызывает одну повторную генерацию. Уже сохранённая история остаётся доступной. Проверить воспроизведение с локальной моделью: `./gradlew dialogueLoopQualityTest`; подробный транскрипт — `build/dialogue-loop-quality.json`.

## Установка и первый запуск

1. Установите Fabric Loader для Minecraft 26.3.
2. Положите JAR MarkAI из beta-архива и Fabric API **для 26.3** в `mods` нужного профиля. Перед заменой сделайте полную копию мира: у старых версий несовместимый читатель нового формата. Оставьте один активный JAR MarkAI. `-sources.jar` в игру не нужен. Обновляйте JAR после закрытия игры.
3. Приручите дикого волка обычными костями до появления сердечек. Если у вас ещё нет живого компаньона, он автоматически станет Walk. Для уже приручённого своего волка посмотрите на него с расстояния до 8 блоков и выполните `/walk tame`. Можно также создать компаньона через `/mark spawn`; `/walk` и `/mark` — равнозначные имена команды.
4. Нажмите **U** для общей панели питомцев; **G** — личный профиль, **H** — личный диалог, **V** — быстрые команды. Общая панель доступна также кнопкой «Все» в заголовке личной. Клавиши переназначаются в управлении Minecraft.
5. Для разговора запустите настроенный AI-сервер. С локальной установленной Ollama в этой рабочей копии достаточно `.\start-ollama.ps1`.

Прямые команды с клавиатуры: **R** — атаковать цель под прицелом, **J** — собрать добычу, **K** — остановить задание, **B** — ко мне, **N** — ждать здесь, **M** — за мной, **I** — сумка. Они работают в игре с закрытыми меню и чатом, без языковой модели. Переназначение: «Настройки → Управление → Назначение клавиш → Компаньон MarkAI».

Fabric Loader и Fabric API устанавливаются отдельно. Ошибка `fabric-api is missing` означает, что не хватает JAR Fabric API. На выделенном сервере установите MarkAI и Fabric API также на клиенте, чтобы пользоваться GUI; мир и действия остаются под контролем сервера.

## Общая панель и общий чат

**U → Питомцы:** карточки всех своих компаньонов со здоровьем, состоянием и переходом в личные профиль, диалог и настройки. Выбор карточки подтверждается сервером. При нехватке места список прокручивается.

**U → Настройки:** защита хозяина, самостоятельные реплики, HUD и дистанция следования применяются ко всем своим текущим питомцам, включая временно выгруженных. Различающиеся значения обозначены «Разные»; имена и характер редактируются отдельно в карточках. Есть выключатель общего чата и разрешение питомцам разговаривать друг с другом.

**U → Общий чат:** сообщение без имени адресовано всем своим доступным питомцам в пределах 32 блоков. Обращение по настоящему имени выбирает адресата независимо от личного выбора. Они видят подписанные реплики, тему игрока и имя собеседника. Питомец может задать другому вопрос по имени, чтобы продолжить беседу; без нового вопроса она заканчивается сама. Общий предел — **10 реплик всех питомцев вместе после твоего сообщения**, а не десять каждому. «Отмена» останавливает запрос и оставшуюся очередь. Уже отправленный вопрос виден во время ожидания, следующий черновик сохраняется.

В обычном чате Minecraft можно использовать `/ma <сообщение>` для общего разговора и `/mo <сообщение>` для личного разговора с выбранным питомцем. Формат `/mo <имя питомца> <сообщение>` обращается к питомцу по имени, даже если выбран другой; его ответ появится в игровом чате. Команды `/m1` нет.

**Обращения по именам работают только в этой общей вкладке.** В личном диалоге отвечает выбранный питомец; упоминание другого не переключает адресата. Обычный чат Minecraft не запускает эти разговоры. Реплика модели не исполняется как команда: движение и бой запускаются проверенными действиями игрока.

Общая история хранит последние 24 сообщения отдельно от личных разговоров и сохраняется в мире по UUID владельца. При отключённой памяти сохраняются только общие предпочтения; сообщения остаются лишь до закрытия мира.

## Личный интерфейс

Панель содержит пять вкладок: профиль с моделью загруженного волка, команды, диалог, воспоминания и настройки. Диалог показывает настоящую историю, состояние запроса и ошибки; Enter отправляет сообщение, «Отмена» отменяет запрос. Колёсико прокручивает историю. В памяти можно выбрать запись, прочитать источник и содержание, удалить её, обновить список и перейти на следующую страницу.

В профиле есть кнопка «Приручить волка» для принятия своего уже приручённого волка. Во вкладке команд и быстром меню **V** доступны «Атакуй цель», «Сбор добычи» и «Стоп». Перед атакой наведите прицел на цель; открытие панели сохраняет направление взгляда. Кнопки подстраиваются под доступную высоту, включая полный экран с масштабом GUI 2 и 4.

В настройках меняются HUD, защита хозяина, самостоятельные реплики, дистанция следования, имя и черты характера. Значения сохраняются для этого компаньона. Если волк не загружен рядом с клиентом, вместо его модели показывается соответствующая подпись.

«Сам говорит» комментирует текущую обстановку и свежие события. Старые вопросы игрока не запускаются повторно; одинаковые и похожие по формулировке недавние реплики отсекаются. При неизменной обстановке между попытками выдерживается пять минут. Сообщение игрока прерывает собственный фоновый автодиалог, выключение режима отменяет ожидаемую автоматическую реплику.

**Shift + ПКМ по компаньону** открывает сумку на 9 слотов. Обычный ПКМ сохраняет кормление и посадку. Сумка доступна только живому владельцу рядом с волком, сохраняет свойства предметов вместе с сущностью и выпадает при смерти. У нового волка после возрождения сумка пустая. Обычные волки не получают этот интерфейс.

## Команды

| Команда | Действие |
| --- | --- |
| `/walk tame` | Принять своего приручённого волка под прицелом, не дальше 8 блоков |
| `/walk attack` | Атаковать видимого врага или дикое животное под прицелом; затем собрать добычу рядом |
| `/walk collect` | Собрать лежащие предметы в сумку в радиусе 16 блоков от места начала задания |
| `/walk stop` | Остановить задание, трюк или ожидаемый ответ AI |
| `/mark spawn`, `/mark respawn` | Создать компаньона; после зарегистрированной смерти восстановить личность в новом теле с пустой сумкой |
| `/mark follow`, `/mark stay`, `/mark come` | Следовать, ждать, подойти |
| `/mark rest`, `/mark wander`, `/mark investigate` | Отдохнуть, погулять рядом, изучить наблюдаемый объект |
| `/mark sethome`, `/mark home` | Запомнить дом, вернуться домой |
| `/mark summon`, `/mark dismiss` | Безопасно призвать того же волка; оставить ждать, сохранив личность и сумку |
| `/mark inventory` | Открыть сумку рядом с волком |
| `/mark ask <текст>` | Написать компаньону |
| `/ma <текст>` | Начать общий диалог; ответы питомцев появятся в обычном чате |
| `/mo <текст>` | Написать выбранному питомцу; ответ появится в обычном чате |
| `/mo <имя питомца> <текст>` | Написать указанному питомцу по его имени |
| `/mark ai on`, `/mark ai off`, `/mark ai status` | Управлять AI и проверить его состояние |
| `/mark status`, `debug`, `brain`, `mood`, `memory` | Посмотреть состояние и диагностику |
| `/mark forget` | Очистить разговоры и воспоминания; обучение сохраняется |

Обращения по именам в общем диалоге обрабатывает вкладка «Общий чат» и команда `/ma`; `/mo <имя> <текст>` адресует только указанного питомца. Простые явные просьбы игрока распознаются до обращения к модели; реплики самих питомцев не становятся приказами миру. `/mo <текст>`, личный интерфейс и `/mark ask` относятся к выбранному компаньону.

### Приручение, атака и сбор добычи

Обычное приручение сохраняет правила Minecraft и может потребовать несколько костей. `/walk tame` принимает именно того волка, на которого вы смотрите: его UUID, здоровье, имеющаяся сумка и собственное имя сохраняются. Неназванный первый компаньон получает имя Walk. Если живой компаньон уже есть, другой приручённый волк остаётся обычным питомцем; существующий Walk не заменяется.

Для атаки подойдите к Walk на 16 блоков и наведитесь на видимого врага или дикое животное. Цель должна находиться в пределах 16 блоков и от вас, и от волка; стена закрывает выбор цели. Хозяина, других игроков, приручённых питомцев и союзников атаковать нельзя. После гибели выбранной цели Walk подбирает доступную добычу в пределах 4 блоков от места её гибели.

При отдельной команде сбора участок имеет радиус 16 блоков от позиции Walk в момент начала задания; область не переезжает вслед за ним. Собираются уже лежащие предметы, включая мясо, ресурсы и вещи. Walk подходит к ним обычной навигацией, дожидается стандартной задержки подбора брошенных предметов и складывает их в свою сумку на 9 слотов. Непоместившиеся предметы и остаток частично принятой стопки остаются на земле. Блоки он не ломает и руду не добывает. Содержимое сумки можно забрать через **Shift + ПКМ**.

Те же задания запускаются фразами `Walk, фас`, `Walk, собери мясо и ресурсы`, `Walk, стоп`. Они работают при выключенном или недоступном AI. Вопрос вроде «Ты умеешь атаковать?» не становится приказом. Команда движения заменяет текущее задание; при опасности сбор уступает защите и отступлению. Незавершённые задания прекращаются при выгрузке волка или выходе из мира и не возобновляются после загрузки; уже собранные предметы сохраняются в сумке.

Предыдущее обучение сохранено: `/walk train голос`, `/walk train ко мне`, `/walk train принеси`; выполнять трюки можно через `bark`, `come`, `fetch`. Лакомство держат в основной руке рядом с волком; навык осваивается за три урока. `/walk skills` показывает прогресс. «Принеси» переносит настоящий предмет, брошенный владельцем, и отдаёт его в инвентарь игрока. При отмене предмет остаётся в мире.

## AI и сохранения

По умолчанию используется локальная Ollama: `http://127.0.0.1:11434`, `qwen3:8b`. Модель и Ollama не входят в JAR или архив исходников. `.\start-ollama.ps1 -Pull` загружает модель при первой установке; повторная загрузка для обычного запуска не нужна.

Настройки AI находятся в `config/markai.json`. Поддерживается также HTTP API формата OpenAI Chat Completions. Удалённый сервер требует явного разрешения и HTTPS; токен берётся из переменной окружения процесса Minecraft. См. [CONFIGURATION.md](CONFIGURATION.md).

Мировой `markai.json` хранит связи UUID, личность, эмоции, настройки, дом, навыки и ограниченную память. Сумка хранится в сохранении самой сущности. Старые записи памяти и привязанная курица из ранних версий мигрируют; обычные животные не заменяются. Текст разговоров дополнительно записывается локально в `logs/markai-chat.jsonl`; этот файл содержит личную переписку. При сбое AI игра продолжает работать, запрос можно отменить или повторить позже.

## Сборка и проверки

```powershell
.\build.ps1
.\build.ps1 runGameTest
```

Нужен JDK 25. `build.ps1` использует локальный JDK из `.tools/jdk`, если он установлен; иначе задайте `JAVA_HOME`. Результат — `build/libs/markai-0.10.4.jar`. Без вспомогательного скрипта: `./gradlew build`.

## Ограничения

Языковая модель может ошибаться, повторяться и неверно понимать сложные просьбы. Навигация использует Minecraft и может не найти путь через препятствия; сообщение об успехе не заменяет фактического прибытия. Нет микрофона, распознавания речи, синтеза голоса или отдельной скелетной анимации: используются речь в чате, штатная модель и звуки волка. Проверка выделенного сервера и проверка GUI в настоящем клиенте учитываются отдельно от компиляции и серверных GameTest.
