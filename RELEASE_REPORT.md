# MarkAI 0.8.2 — хоткеи команд

21 октября 2026. Minecraft 26.3 / Fabric / Java 25.

## Implemented

Добавлены переназначаемые прямые команды: R — атаковать цель под прицелом, J — собрать добычу, K — остановить задание, B — ко мне, N — ждать здесь, M — следовать, I — открыть сумку. Настройки находятся в обычном управлении Minecraft, категория «Компаньон MarkAI»; есть русские и английские названия.

Хоткеи работают только в загруженном мире с закрытым экраном. В чате, инвентаре и панели компаньона команды не отправляются; нажатия не откладываются до закрытия меню. Несколько накопленных нажатий одной команды объединяются в одно за тик. Используются прежние серверные проверки владельца, дальности и цели; языковая модель не требуется. G/H/V сохранены.

## Build and test results

`gradlew build runClientGameTest --console=plain` — **BUILD SUCCESSFUL**, 672 проверки логики/HTTP. Настоящий клиентский сценарий прошёл: N посадила реального волка, M сняла посадку, N внутри панели не отправила приказ, I открыла настоящую сумку через сервер. Прежние проверки диалога, G/H/V, окна, полного экрана с GUI 2/4, переноса предметов и восстановления окна тоже прошли. Сохранены 16 снимков и отчёт раскладки.

Отчёты: `build/hotkeys-validation.log`, `build/client-gametest/fullscreen-ui-validation.json`, `build/client-gametest/screenshots`; в архиве — `validation/`.

Серверные 31/31 сценариев и пять живых проверок модели последний раз выполнялись для 0.8.1. В 0.8.2 серверная логика и провайдер диалога не менялись, эти прогоны повторно не запускались. Подробности предыдущего исправления сохранены в TESTING.md и VALIDATION.md.

## Architecture

`MarkAIClient` регистрирует стандартные KeyMapping и отправляет существующий `CompanionNetwork.Action`. Привязки сохраняет сам Minecraft. Новых сетевых пакетов и формата сохранений нет.

## Partially implemented

Прямые хоткеи назначены семи основным командам. Остальные действия доступны через V, панель или slash-команды.

## Known issues

Установленный игровой процесс получает новые клавиши после перезапуска Minecraft. Клавиши могут пересекаться с другими модами; их можно изменить в управлении. Точное состояние обновления — `dist/install-walk.log`.

## Next development priorities

Продолжить план развития компаньонов после проверки новых клавиш владельцем. Исправления диалога 0.8.1 входят в эту сборку.
