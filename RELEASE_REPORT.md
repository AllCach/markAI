# MarkAI 0.10.0 — общая панель и групповой чат

Здесь описана предыдущая установленная сборка. Проверки следующей beta-версии и границы ручной проверки: [BETA_TESTING.md](BETA_TESTING.md).

21 октября 2026. Рабочий проект: D:/dev/markAI. Minecraft 26.3 / Fabric / Java 25.

## Что изменилось

- **U** и кнопка **«Все»** открывают общую панель: карточки своих питомцев, общий чат и общие настройки. Карточки показывают настоящее здоровье и состояние и открывают личные профиль, диалог и настройки после подтверждения выбора сервером.
- Защита хозяина, самостоятельные реплики, HUD и дистанция следования применяются ко всем своим текущим питомцам, включая выгруженных. Различия показаны как «Разные». Имена и характер остаются личными; чужие компаньоны не затрагиваются.
- Отдельный общий чат учитывает настоящие имена, общий контекст и конкретного собеседника. Отклик по имени действует только в этой вкладке. Личный диалог относится к выбранному питомцу; обычный чат Minecraft не запускает диалогов питомцев.
- Питомцы могут продолжить беседу вопросом другому по имени. Общий предел — **10 реплик всех питомцев вместе после одного сообщения игрока**. Они могут закончить раньше; очередь нельзя продлить репликой модели. Есть счётчик ожидания и отмена всей очереди.
- Если модель пропускает имя собеседника в адресном ответе, сервер добавляет настоящее имя из реестра. Явный новый вопрос другому питомцу сохраняет выбранного адресата. При ответах учитываются исходная тема игрока, подписанные реплики и характер текущего говорящего.
- Общая история ограничена 24 сообщениями и хранится по UUID владельца отдельно от личной. В schemaVersion=1 добавлено необязательное поле groups; прежние файлы читаются. При memoryEnabled=false переписка не сохраняется. Ответы модели не исполняют действия мира; явные команды игрока проходят прежние проверки.

### История 0.9.0 — совместная проверка нескольких компаньонов и групповых команд

21 октября 2026. Актуальная рабочая папка: D:/dev/markAI. Первоначальная совместная проверка выполнена в D:/dev/markAI-0.9.0; затем проверенный проект перенесён сюда по просьбе владельца. Minecraft 26.3 / Fabric Loader 0.19.5 / Fabric API 0.163.0+26.3 / Java 25.

#### Implemented

За основу взяты свежие исходники основной папки, включая уже добавленные групповые команды. Их реализация сохранена; повторного создания групповой системы не было. Перед доработками выполнена полная совместная проверка исходного состояния.

- Реестр по UUID компаньона с отдельными индексами владельца и тела; до восьми волков на игрока. У каждого свои память, навыки, настройки, дом, инвентарь и состояние поведения. Выбор и записи сохраняются в schemaVersion=1, старый массив читается с точной резервной копией перед миграцией.
- Существующие Ctrl-команды для своих компаньонов: атака, сбор, стоп, ко мне, ожидание, следование, отдых, прогулка, домой, осмотр. Один пакет и одна общая серверная операция; цель атаки определяется один раз. Выбор не меняется, чужие питомцы не затрагиваются, недоступные участники пропускаются. Общий стоп отменяет свои задания даже у временно выгруженных компаньонов.
- Существующие карточки, стрелки, колесо над областью выбора и Shift+V сохранены. Обычные приказы относятся к выбранному волку.
- При ожидаемом ответе другого компаньона панель учитывает общий лимит генерации и сохраняет черновик. Запоздалый ответ остаётся в своей истории, не попадая в статус выбранного другого питомца. Во время подтверждения переключения изменение состояния блокируется, при отказе/таймауте кнопки восстанавливаются.
- Загрузка отвергает повторяющиеся логические UUID вместо молчаливого перезаписывания записи. Общий итог задания сообщает о принятии приказа, не выдавая начало движения/атаки за завершение.

#### Architecture

Сохранены CompanionRegistry, CompanionStore, существующий Action("all:<команда>"), WolfWorkRuntime и серверная проверка владельца. Группа обходит только записи игрока соединения; реальная навигация, бой и инвентари выполняются прежними волчьими системами. Сессии и страницы памяти связаны с UUID компаньона, а статусы панели сверяются с текущим выбором. Никакого нового группового координатора вместо текущего исполнения не вводилось.

#### Partially implemented

0.9.0 содержит нескольких волков и текущие групповые команды. Курица Mark, разные роли видов, охрана/патруль/исследование зоны 32 блока, Balanced AI, Журнал Натуралиста и голос ещё не реализованы. Это не объявляется готовой Living World 1.0.

#### Known issues

Генерация ответов выполняется последовательно. Сложность и естественность речи зависят от модели. Проверка переноса выполнена на тестовых данных, пользовательский мир не мигрировался. Длительная нагрузочная сессия со множеством игроков не проводилась. Новый мировой формат несовместим со старым читателем; пробовать версию следует в отдельном профиле и на копии мира.

После первоначальной отдельной проверки по просьбе владельца «замени в игре» 0.9.0 установлена в основной игровой профиль. Прежний JAR, настройки и данные MarkAI сохранены; подробности — [INSTALLATION.md](INSTALLATION.md). Затем проверенные исходники перенесены в D:/dev/markAI. Установка и перенос не запускают пользовательские миры; миграция пользовательского мира в этих операциях не проверялась.
