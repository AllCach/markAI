# Граница видов компаньонов

Текущий код `dev-beta` поддерживает `minecraft:wolf` и `minecraft:chicken`. Реестр отделяет UUID личности, владельца и физической сущности; старое сохранение без поля вида трактуется как волк. Неизвестный вид при загрузке отклоняется, чтобы не подменять животное.

| Возможность | Волк | Курица |
| --- | --- | --- |
| Следовать, подойти, ждать, отдыхать, говорить | Да | Да |
| Бой, защита, сбор лежащих предметов | Да | Нет |
| Сумка и собачьи трюки | Да | Нет |
| Территориальная роль | Охрана, патруль, исследование | Дозор |
| Опыт и таланты | Волчий набор | Куриный набор |

Видовые команды проверяются на сервере и скрываются либо отключаются в GUI для неподдерживаемого вида. Обычный ПКМ с костью не регистрирует волка; Shift + ПКМ после удачного приручения регистрирует **ту же** сущность. Курица регистрируется через Shift + ПКМ с семенами. Чужой питомец и повторная регистрация отклоняются. Удаление из MarkAI сохраняет животное в мире.

Сборка Java текущего кодового пакета прошла; полная игровая приёмка, два клиента и жизненный цикл смерти/выгрузки/измерений ещё открыты. См. [../IMPLEMENTATION_STATUS.md](../IMPLEMENTATION_STATUS.md) и [../TESTING.md](../TESTING.md).
