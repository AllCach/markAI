# Настройки MarkAI 0.10.1 beta

Ctrl + поддерживаемая команда отправляет один групповой приказ своим компаньонам; Ctrl + I не открывает несколько сумок. Shift + V переключает выбранного компаньона. Параметры личности, памяти, дома и автодиалога относятся к выбранному питомцу. Настройки привязок клавиш остаются стандартными настройками Minecraft.

Текущая версия исходников — 0.10.1 beta; до её установки локальная игра остаётся на 0.10.0. Ollama можно установить обычным инсталлятором или поместить переносимую копию в `.tools/ollama`. Приложенный `start-ollama.ps1` поддерживает оба способа, сохраняет заданный `OLLAMA_MODELS` и запускает сервер только на `127.0.0.1`. Проверка с фальшивым Ollama не скачивает ни программу, ни модель. Первичная установка и ограниченный beta-архив описаны в [BETA_README.md](BETA_README.md); условия тестирования — [BETA_TESTING.md](BETA_TESTING.md).

Клавиши команд меняются в обычном меню управления Minecraft, категория «Компаньон MarkAI»: R — атака выбранной прицелом цели, J — сбор добычи, K — стоп, B — ко мне, N — ждать, M — следовать, I — сумка. С открытым экраном, в том числе чатом, команды не отправляются. Настройки клавиш сохраняет Minecraft в options.txt; markai.json для этого не нужен.

Ручной диалог допускает одну повторную генерацию, если модель повторила недавний длинный ответ. Обе попытки используют общий `timeoutSeconds`; повторная генерация сохраняет исходное сообщение и историю. Короткие подтверждения, достоверные координаты и явная просьба повторить ответ исключены из этой проверки. Для самостоятельных реплик действует прежнее подавление повторов.

`config/markai.json` находится в игровом профиле **того процесса, который выполняет серверную логику**: в одиночной игре это клиент, на выделенном сервере — сервер. Настройки провайдера читаются при запуске логического сервера; после изменения перезапустите мир. Неверный JSON сохраняется в отдельный `.invalid-<UUID>.bak`, затем создаются безопасные значения по умолчанию.

## Локальная Ollama

Минимальная конфигурация совместима со старыми установками:

```json
{
  "provider": "ollama",
  "ollamaUrl": "http://127.0.0.1:11434",
  "ollamaModel": "qwen3:8b",
  "authentication": "none",
  "remoteAIEnabled": false,
  "timeoutSeconds": 120,
  "requestCooldownSeconds": 5,
  "thinking": true,
  "temperature": 0.35,
  "maxOutputTokens": 1024,
  "retries": 1
}
```

`baseUrl` и `model`, если заполнены, переопределяют старые `ollamaUrl` и `ollamaModel`. Нативный транспорт Ollama принимает только локальный HTTP-адрес и корневой путь; разрешение удалённого AI этого не меняет. `thinking` применяется к Ollama. Модель должна быть установлена на AI-сервере отдельно.

## OpenAI-совместимый HTTP API

```json
{
  "provider": "openai-compatible",
  "baseUrl": "http://127.0.0.1:8080/v1",
  "model": "your-installed-model",
  "authentication": "none",
  "remoteAIEnabled": false,
  "structuredOutputs": true,
  "timeoutSeconds": 120,
  "requestCooldownSeconds": 5,
  "temperature": 0.35,
  "maxOutputTokens": 1024,
  "retries": 1
}
```

Транспорт отправляет `POST /chat/completions` относительно указанной базы; путь полного endpoint также допустим. Требуется ответ Chat Completions с одним завершённым сообщением и JSON `action`/`say` внутри `message.content`. Если сервер поддерживает только JSON Object, отключите `structuredOutputs`; проверка результата остаётся строгой.

`maxOutputTokens` передаётся как `max_tokens`, а `temperature` — без изменения имени. Транспорт использует этот набор параметров Chat Completions для всех моделей и не переключается автоматически на `max_completion_tokens`. Совместимость с reasoning-моделями и удалёнными endpoint, требующими других параметров или фиксированной температуры, живыми запросами не подтверждена.

Для удалённого сервиса задайте HTTPS-базу и `remoteAIEnabled: true`. Для Bearer-аутентификации задайте `authentication: "bearer"` и `apiKeyEnvironment: "MARKAI_API_KEY"`; сам ключ должен быть в окружении процесса, запускающего Minecraft/сервер. В конфиг, мировой JSON, скриншот GUI или архив ключ не записывается. Клиентские пакеты не позволяют менять адрес провайдера или ключ.

## Ограничения и параметры игры

| Поле | Значение по умолчанию | Допустимые значения |
| --- | --- | --- |
| `timeoutSeconds` | 120 | 5–300 |
| `requestCooldownSeconds` | 5 | 2–60 |
| `temperature` | 0.35 | 0–2, конечное число |
| `maxOutputTokens` | 1024 | 64–4096 |
| `retries` | 1 | 0–3 дополнительных попытки |
| `maxDialogueLength` | 240 | 32–240 символов |
| `automaticConversationSeconds` | 60 | 0 отключает; 1–3600 с минимальной задержкой 30 секунд; нужно разрешение autochat |
| `memoryEnabled` | true | true/false; использование и накопление памяти, запись журнала диалога |
| `hudVisible` | true | Начальное состояние HUD |
| `followDistance` | 4 | 2–16 блоков |
| `defensiveBehavior` | true | Начальная настройка защиты |
| `debugMode` | false | Диагностика |
| `voiceEnabled` | false | Зарезервировано; голосовой движок не реализован |

При `memoryEnabled: false` запросы к AI не содержат сохранённую историю диалога, извлечённые факты, воспоминания и сохранённые недавние события. Новые разговоры и воспоминания о событиях не накапливаются; новые пары запрос/ответ не записываются в `logs/markai-chat.jsonl`. Ранее сохранённые записи остаются в мире и доступны для просмотра и удаления через интерфейс. Текущее состояние мира, характер, эмоции и выученные навыки продолжают использоваться.

`/mark forget` очищает разговоры, воспоминания и сохранённые недавние события, которые могут попасть в контекст модели; навыки сохраняются. Команда не удаляет уже записанную переписку из `logs/markai-chat.jsonl` и его ротаций `.1`/`.2`: диагностические файлы очищаются отдельно в папке `logs`.

Вкладка «Настройки» меняет сохранённые параметры конкретного компаньона: HUD, защиту, самостоятельные реплики, дистанцию, имя и характер. Эти параметры отделены от настроек HTTP-провайдера. Имя ограничено 32 символами, значения характера — 0–100 в интерфейсе.

Самостоятельные реплики используют текущий снимок мира и до восьми недавних автоматических фраз, без прежней переписки, старой команды и сохранённой точки дома. Одинаковая обстановка даёт паузу минимум пять минут, изменившаяся — соблюдает `automaticConversationSeconds` (минимум 30 секунд). Точные и близкие повторы не отправляются в чат. Последние автоматические фразы хранятся только до выхода из мира и не становятся словами игрока или записями долгосрочной памяти. Ручной вопрос прерывает свой фоновый запрос; отключение autochat отменяет ожидаемый ответ. Ошибка фонового запроса не создаёт сообщение об ошибке в игровом чате.

## Приручение и задания Walk

Приручение и задания не требуют включённого AI или новых полей в `config/markai.json`. Успешное обычное приручение костями автоматически делает волка компаньоном, если у владельца нет живого компаньона. `/walk tame` или кнопка «Приручить волка» принимают уже приручённого собственного волка под прицелом в пределах 8 блоков. Существующий живой Walk сохраняется; другое животное его не заменяет. Принятие сохраняет UUID, здоровье, содержимое сумки и собственное имя волка.

| Действие | Условия и границы |
| --- | --- |
| `/walk attack`, «Атакуй цель», `Walk, фас` | Хозяин находится не дальше 16 блоков от Walk. Видимый враг или дикое животное под прицелом должны быть в пределах 16 блоков и от хозяина, и от волка. Игроки, питомцы и союзники защищены |
| Сбор после атаки | После гибели выбранной цели: доступные лежащие предметы в радиусе 4 блоков от места гибели |
| `/walk collect`, «Сбор добычи», `Walk, собери мясо и ресурсы` | Хозяин рядом, до 16 блоков. Радиус участка — 16 блоков от позиции волка в момент начала задания; вместимость сумки — 9 слотов |
| `/walk stop`, «Стоп», `Walk, стоп` | Отменить текущее задание, трюк и ожидаемый ответ AI |
| **Shift + ПКМ** или `/walk inventory` | Открыть сумку своего живого компаньона рядом |

Радиусы заданий фиксированы. Сбор учитывает обычную задержку подбора Minecraft и доступность пути; Walk не ломает блоки и не добывает руду. В сумку переходит только реально поместившееся количество: остальные предметы остаются на земле. Сбор прерывается при возникновении боя или опасности. Новая команда движения заменяет задание; выгрузка волка, отключение владельца и завершение серверной сессии отменяют его. Задания не сохраняются для автоматического продолжения после входа в мир, содержимое сумки сохраняется.

## Общие настройки питомцев

Откройте **U → Настройки**. Защита хозяина, самостоятельные реплики, HUD и дистанция следования меняются у всех своих текущих питомцев; чужие не затрагиваются. «Разные» означает, что личные значения различаются. Первый клик по смешанному переключателю включает его у всех. Имена и черты характера остаются личными.

«Общий чат» включает общую вкладку; «Разговоры питомцев» разрешает продолжать её вопросами друг к другу по настоящим именам. Разговоры разрешены по умолчанию. Ограничение **10 реплик питомцев всего после одного сообщения игрока** фиксировано на сервере и не увеличивается настройкой или ответом ИИ. Для продолжения после лимита нужно новое сообщение игрока. Нажатие «Отмена» прерывает текущую генерацию и очередь.

Общие предпочтения и последние 24 сообщения находятся в необязательном поле `groups` мирового `markai.json`, отдельно для каждого UUID владельца. `schemaVersion` остаётся 1; файлы 0.9.x без этого поля читаются. Личные настройки каждого питомца сохраняются на прежнем месте. `memoryEnabled=false` запрещает сохранение общей переписки и использование истории прежних разговоров для генерации; предпочтения сохраняются. Личный чат и обычный чат Minecraft не маршрутизируют сообщения по именам.
