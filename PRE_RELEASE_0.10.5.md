# MarkAI 0.10.5 — каркас пререлиза

Статус: **подготовка, не готовый релиз**. Ветка: `feature/0.10.5-scaffold`, базовый коммит: `b85e1c5f6a186f1e0e886f5e7a44974116d533b5`.

## Что подтверждено статическим просмотром

- `gradle.properties` задаёт Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.163.0+26.3, Loom 1.18.4 и Java 25.
- `CompanionRegistry<T>` уже является обобщённым реестром, использует UUID компаньона, владельца и сущности, поддерживает отдельный выбор и ограничение до восьми компаньонов на владельца.
- В `MarkAIMod.java` присутствуют интеграции для Wolf и Chicken, но одного импорта класса недостаточно, чтобы считать курицу-компаньона завершённой функцией.
- В сборке объявлено несколько отдельных тестовых наборов и GameTests.
- Коммит `Pre-pre-release` добавил проверки реестра, удаления компаньона, сохранности сумки, групповых команд и клиентского интерфейса.

Это просмотр опубликованного исходного кода, а не полный аудит или подтверждение успешной сборки. Локальные незакоммиченные изменения недоступны через GitHub, и тесты из этой среды не запускались.
