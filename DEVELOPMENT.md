# Разработка MarkAI

Текущая ветка интеграции — `dev-beta`, версия исходников `0.11.2-beta.1`. Java 25, Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.163.0+26.3, Loom 1.18.4 и Gradle Wrapper 9.7.1 указаны в файлах сборки. Используются официальные имена Minecraft.

## Сборка

На Windows `.\build.ps1 build` выбирает локальный JDK в `.tools/jdk`; если его нет, установите JDK 25 и задайте `JAVA_HOME`. Команда напрямую: `.\gradlew.bat build --console=plain`. Для проверки только компиляции: `.\gradlew.bat compileJava --console=plain`. Ни одна из этих команд не загружает модель.

JAR появляется в `build/libs`; `betaDist verifyBetaDist` собирает ZIP в `dist` и проверяет список файлов, контрольную сумму, метаданные и отсутствие тестовых классов. Не публикуйте старый JAR под новым коммитом. `bin/`, локальные миры, логи, ключи и `.tools/` в коммит и архив не входят.

## Структура и работа

Серверная интеграция находится в `MarkAIMod`; видовые действия — в отдельных runtime. Реестр, сохранение, память, журнал, сеть и AI имеют отдельные пакеты. См. [ARCHITECTURE.md](ARCHITECTURE.md). Состояние реализации и оставшаяся работа: [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md), [WORK_PLAN.md](WORK_PLAN.md).

Работайте пакетами: сначала причина и изменения, затем одна проверка пакета. Для релизного кандидата используйте полный набор из [TESTING.md](TESTING.md) на точном коммите. Файлы мировых сохранений обновляйте только на копиях; не используйте живой мир как тестовую фикстуру. Клиентские классы не должны требоваться выделенному серверу. Запросы к модели выполняются вне игрового потока; результаты применяются после повторной проверки владельца, сущности и поколения запроса на серверном потоке.
