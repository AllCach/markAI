# Разработка

Цель проекта — Minecraft Java 26.3, Fabric Loader 0.19.5, Fabric API 0.163.0+26.3, Java 25. Версии зафиксированы в `gradle.properties`, Gradle Wrapper использует 9.7.1. Проект работает с официальными именами классов Minecraft; примеры под другие версии и Yarn нельзя переносить без проверки.

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-25'
.\gradlew.bat build
.\gradlew.bat runGameTest
.\gradlew.bat runClient
```

`build.ps1` принимает одно имя задачи и автоматически выбирает локальный JDK из `.tools/jdk`, если он есть. Сборка не требует скачивать языковую модель. `.tools`, `.gradle`, `build` и игровые миры не включаются в исходники.

## Исходники и проверки

`src/main` содержит общий код и клиентские классы с отдельным entrypoint и `@Environment(CLIENT)`. Логический сервер не должен ссылаться на GUI или `Minecraft`. `src/aiChecks` содержит запускаемые Java-проверки и поддельные HTTP-серверы. `src/brainChecks` проверяет исходный `MarkBrain`. `src/gametest` — отдельный тестовый Fabric-мод; он не попадает в релизный JAR.

При добавлении действия обновите типизированную модель, серверное выполнение, валидацию, сетевой список разрешений и работающий интерфейс. Не передавайте из фоновой задачи сущности, мир или `ServerPlayer`: соберите значения заранее и применяйте ответ на серверном потоке с проверкой поколения запроса.

Перед изменением API проверьте методы в локальном Minecraft JAR и исходниках установленного Fabric API. В 26.3 GUI использует `extractRenderState(GuiGraphicsExtractor, ...)`, события `KeyEvent` и `ContainerInput`; текущий экран доступен через `Minecraft.gui.screen()`.

## Сохранение и миграции

Сохраняйте UUID владельца и личности. При чтении старых данных нормализуйте отсутствующие поля и сохраняйте происхождение воспоминаний. Не создавайте нового волка только потому, что старый выгружен. Предметы сумки сериализуются штатными кодеками вместе с сущностью, а не строковыми ID предметов в отдельном JSON.

Используйте отдельный тестовый мир. Изменение данных существующего пользовательского мира проверяйте на копии. Проверки сети должны включать неизвестные действия, чужую личность, ограничения размера и частоты. Проверки GUI и живой модели описаны в [TESTING.md](TESTING.md).
